# Car Sales Data Analysis

## About the Project

This is my minor project for data analysis. In this project, I have used Python to explore a car sales dataset and understand different patterns in the data.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google collab Notebook

## Work Done

- Checked the dataset's rows, columns, and data types.
- Separated numerical and categorical columns.
- Checked for duplicate values and missing data.
- Checked for possible outliers in the dataset.
- Created different charts to understand the data.
- Studied the relationship between car price, mileage, year of manufacture, engine size, and fuel type.

## Visualizations

I created the following charts:

1. Histogram of car prices
2. Count plot of car manufacturers
3. Box plot of price by fuel type
4. Scatter plot of mileage and price
5. Scatter plot of engine size and price
6. Correlation heatmap

## Key Findings

- Car prices are right-skewed, with many cars in the lower price range and fewer expensive cars.
- Ford and Volkswagen are among the most common manufacturers in the dataset.
- Newer cars generally have lower mileage.
- Car prices generally increase with the year of manufacture.
- Cars with higher mileage generally have lower prices.
- Engine size has a positive relationship with car price, although this does not apply to every car.

## How to Run

1. Download or clone this repository.

2. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn
   ```

3. Open `Monu_Cars_EDA_project.ipynb` in Jupyter Notebook or Google Colab.

4. Make sure the CSV dataset is available in the correct folder.

5. Run the notebook cells to view the analysis and charts.
